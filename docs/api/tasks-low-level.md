# `visbench.tasks.low_level`

Signal-level properties recoverable without naming an object. Two of the four
compute their target **from the frame** rather than reading it from disk, which
makes them the cheapest kind of probe to add and the easiest to fool yourself
with — see the gauntlet in `visbench/tasks/low_level/README.md`.
